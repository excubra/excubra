Auf dem Server

Neuen Zugang anlegen, Startpasswort und TOTP-Geheimnis werden einmalig ausgegeben:

excubra server user add <name>

Passwort neu setzen, Zugang sperren oder freigeben:

excubra server user passwd <name>
excubra server user disable <name>
excubra server user enable <name>
